# Power_Bi_Sales_Inventory_Dashboard-
Business Performance Analytics Dashboard

An end-to-end Power BI project focused on transforming raw sales data into actionable business insights. The project includes data cleaning, validation, modeling, and dashboard development to analyze sales performance, profitability, regional trends, product performance, and the impact of discounts on profit.

Key Features
KPI monitoring for Sales, Profit, Orders, and Customers
Regional sales and profitability analysis
Product performance and profit contribution tracking
Discount vs. Profit analysis
Interactive filters and drill-down capabilities
Executive summary dashboard for decision-making
Tools & Technologies
Power BI
Power Query
DAX
Data Modeling
Data Validation & Cleaning
Project Outcomes
Identified top-performing products and regions
Highlighted key profit drivers and loss-making areas
Revealed the relationship between discounts and profitability
Enabled data-driven decision-making through interactive visualizations
